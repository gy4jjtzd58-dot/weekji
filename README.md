# week记

适用于 Windows 的透明桌面计划应用。一个主窗口中，左侧显示一周七天的上午、下午、晚上和备注，右侧是随时记录事项的随心记。拖动中间分隔条可以调整两栏宽度。

## 功能

- 周计划与随心记合并在一个主窗口中，使用统一的深蓝色 W 波浪图标和一个桌面入口。
- 透明界面、柔和墨黑任务文字，支持调整窗口大小、位置和左右栏比例。
- 双击格子编辑安排，切换上周、本周和下周，各周分别保存；编辑窗口与主窗口共用同一进程。
- 随心记停止输入后自动保存，支持多行中文，继续使用原有 `notes.txt` 文件。
- 主窗口固定在桌面层，点击时保持在普通应用下面。
- 不显示任务栏按钮；一个程序进程和一个系统托盘图标统一管理显示、隐藏和退出。
- 显隐快捷键支持 `Ctrl+D`、`Ctrl+Alt+D`、`Ctrl+Shift+D` 或关闭；`Win+D` 显示桌面时仍保留便签。
- 默认在独占或无边框全屏时自动休眠：隐藏界面、暂停刷新并让出快捷键，返回后恢复原可见状态且不抢焦点。
- 任务变化时更新对应格子，静止时不逐秒读取全部任务；使用静态透明外观，没有背景动画或逐段文字的模糊阴影。
- 从托盘打开外观设置，分别调整周计划和随心记的字号、文字深浅、背景透明度及行高，支持实时预览。
- 所有内容保存在本机，不需要账户和网络服务。

## 技术来源

界面和功能代码使用 C# 编写，基于微软 .NET Framework、WPF、Windows Forms 和 Win32 接口。图标嵌入程序，不需要额外的常驻进程。

窗口层级设计参考了 [Rainmeter 的公开实现思路](https://github.com/rainmeter/rainmeter)，以及[微软的 Windows 窗口管理文档](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)。本仓库包含独立应用的源码、图标资产和构建脚本。

## 构建与运行

在安装了 .NET Framework 4.x 的 Windows 10/11 电脑上，从项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Build.ps1
```

构建会运行中文内容保存与日期计算检查，并生成 `dist\WeekJi\App\WeekJi.exe`。启动应用：

```powershell
.\dist\WeekJi\App\WeekJi.exe --week
```

正式图标已包含在 `assets` 中。如需从矢量路径重新生成图标，可运行 `scripts\BuildBrandIcon.ps1`，再重新构建程序。

将整个 `WeekJi` 文件夹放到需要的位置，然后运行其中的 `InstallShortcuts.ps1`，即可创建一个“week记”桌面快捷方式。加上 `-StartAtLogin` 可创建开机启动快捷方式：

```powershell
powershell -ExecutionPolicy Bypass -File .\InstallShortcuts.ps1 -StartAtLogin
```

脚本保留旧参数 `-StartNotesAtLogin` 的兼容别名。应用也接受旧的 `--notes` 启动参数，它与 `--week` 都会打开同一个合并后的主窗口。

## 使用

双击左侧格子后输入安排，点击保存或按 `Ctrl+Enter`。点击取消或按 `Esc` 可放弃格子编辑。

右侧随心记会自动保存，也可点击“保存”，或按 `Ctrl+S`、`Ctrl+Enter` 立即保存。点击顶部“随心记”收起右侧笔记，再点一次展开；收起前会先保存内容。收起后周计划填满主窗口，展开时恢复笔记栏宽度，收起或展开的状态会保留到下次启动。点击主窗口右上角 `−` 或 `×` 收起到托盘；双击“week记”桌面快捷方式，或从托盘菜单选择“显示 week记”恢复界面，选择“退出”完全退出程序。

默认按 `Ctrl+D` 收起当前可见的主窗口和外观设置，再按一次恢复收起前可见的界面。可在托盘菜单“显隐快捷键”中切换为 `Ctrl+Alt+D`、`Ctrl+Shift+D`，或关闭快捷键。所选组合键在非休眠时由本应用使用；如与其他软件冲突，可更换组合键或关闭。未成功注册快捷键时仍可使用窗口按钮和托盘菜单。休眠期间会释放该快捷键，结束休眠后重新注册。`Win+D` 与 Windows“显示桌面”仍会保留便签。

拖动顶部日期区域可以移动窗口；拖动边缘可以调整窗口大小；拖动中间分隔条可以调整周计划和随心记的宽度比例。随心记展开时，主窗口通常最小为 1120×430；收起右侧后可缩小到 802×430。窗口大小、位置和随心记宽度会在下次启动时恢复。

### 全屏与休眠

托盘菜单默认勾选“全屏时自动休眠”。独占全屏和无边框全屏采用相同策略，播放器、浏览器的全屏也会触发；可在托盘取消该选项。

进入全屏时，应用尝试保存随心记，隐藏自身窗口，暂停任务刷新和桌面层级调整，并让出显隐快捷键。退出全屏后只恢复原先可见的界面，不主动激活窗口或抢走前台焦点。

托盘“手动休眠”需要手动取消；退出全屏不会结束手动休眠。休眠持续约 30 秒后，应用会释放已保存且可重建的桌面窗口，恢复时再按原状态重建。尚未保存的输入保留在内存中；保存失败不会弹出对话框打断全屏应用。

### 外观设置

右键点击屏幕右下角的 week记 托盘图标，选择“外观设置”。周计划与随心记可以分别调整字号、文字深浅、背景透明度和行高。

拖动滑块时实时预览，背景透明度仅改变背景，不影响正文。点击“保存”会持久保存设置；点击“取消”或设置窗口右上角的 `×`，会恢复打开设置窗口前的外观。“恢复默认”只更新本次预览，仍需点击“保存”才会保留。

## 本地数据

运行后，便携目录中的 `Data` 文件夹保存每周安排、随心记以及窗口大小和位置。每周安排放在以该周周一日期命名的 `YYYY-MM-DD` 子目录中，随心记保存在 `notes.txt`，外观设置保存在 `appearance.ini`。

程序位于 `WeekJi\App\WeekJi.exe`，数据位于旁边的 `WeekJi\Data` 文件夹。备份时先保存并退出应用，再复制整个 `Data` 文件夹；移动整个 `WeekJi` 便携目录会一起保留内容。从旧版迁移时保留原有 `Data`，任务与随心记的数据格式保持兼容。

仓库不包含用户的任务安排、随心记、窗口配置、历史备份或本机安装路径。这些文件也在 `.gitignore` 中排除。
